# Party Room 1: Emily's passcode

The first puzzle. All the kids together, once, right after the call drops and the spotlight comes on. They find four numbers hidden in the games, put them in the right order, and type them on the laptop at the main screen. The screen unlocks, the detective video plays, the real game starts.

The code is **5817**, the same as `screenCode` in `src/content/rooms.ts`. Each number comes from one game. If you change the code, change the four digits below and the setting in the code, nothing else moves.

| Order | Game | Digit | How they get it |
| --- | --- | --- | --- |
| 1 | Cup pong | 5 | Two pyramids of ten red cups. Five of the twenty cups have a ping pong ball sitting in them. Count the balls. |
| 2 | Playing cards | 8 | A stack of number cards. Every value appears at least twice except the eight. |
| 3 | Giant Jenga | 1 | Written on a block hidden inside the tower. The tower has to come down. |
| 4 | Dominos | 7 | One face-down tile has Emily's mark on the back. Add its pips. |
| Key | Ping pong table | | Emily's note, taped underneath. Says there are four numbers in the games and how to find each. |
| Order | Balloons | | One balloon holds a slip with the order of the four games. |

Nothing tells them to start at the ping pong table. The spotlight does.

## 1. Ping pong table: Emily's note

Tape a folded index card to the underside of the table, dead centre, so it's found by whoever crawls under or flips it. Write it by hand, all lowercase, no periods, the way Emily texts.

```
if youre reading this im gone and i didnt leave on my own

my passcode is four numbers. i hid them in the games
so only people who actually look would find them

tower. its inside
tiles. find my camera. add it up
cups. count the balls
cards. the one thats alone

the order is in the air
```

"The order is in the air" is the balloons. The four lines are deliberately not in code order, so the note alone doesn't give the order away. If the kids read the four lines and run straight to the games, good. The note is also the hint sheet for the leader in the room: each line is the hint for that game.

## 2. Cup pong: the 5

**Prep.** The normal setup: two pyramids of ten red cups, one at each end of the table. Twenty cups total, all the same colour. Drop a ping pong ball into **five** of the cups, split across both pyramids so neither side has an obvious shape, for example three on one side and two on the other. It looks like a game somebody walked away from mid-round. That's the whole clue. Count the balls, get 5.

No other balls anywhere in the room. Not on the table, not on the floor, not in a pocket. Every loose ball is a wrong answer waiting to happen.

**Watch out.** Keep the five balls split across both pyramids. If all five sit on one side, a kid reads it as "five on this side, so maybe ten." If a kid knocks a pyramid over, the balls scatter, so the leader in the room should know where the five were and put them back. Count them out loud when you set up and again right before the doors open.

**Hint if stuck.** "Cups. Count the balls."

**Other digits**, in case you change the code: that many balls in the twenty cups. Avoid using 0 as the cup digit, since there's nothing to count; move the 0 to the Jenga block or the domino instead.

## 3. Giant Jenga: the 1

**Prep.** Build the tower. Pick a block that will be the middle block of a layer somewhere in the lower half, so its long sides are completely hidden by the blocks above and below. Write a big black **1** on one long side with a marker, with a clear base and flag so it can't be read as a stray line. Nothing on any other block.

**What they do.** Pull blocks or knock it over. Either way the 1 turns up. Thirty kids will knock it over in about four seconds, which is fine. The point is that they have to take it apart.

**Watch out.** Don't write on an end face. Ends are visible from the outside and a kid will spot it from the doorway.

**Hint if stuck.** "Tower. It's inside."

## 4. Playing cards: the 8

**Prep.** Build a stack of about twenty number cards from the two poker decks, face down, squared up, sitting on the table with the rest of the cards nowhere in sight. Use only 2 through 10. Every value in the stack appears two or three times, in any suits, except the **8**, which appears exactly once. No aces, no face cards, no jokers, so nobody has to argue about what an ace or a jack is worth. Shuffle it.

Example stack of 21: 2 2, 3 3 3, 4 4, 5 5 5, 6 6, 7 7 7, 9 9, 10 10 10, and one 8.

**What they do.** Spread the cards out, sort by value, see which one has no partner.

**Watch out.** Check the stack twice. If any other value is alone, the puzzle has two answers. If a kid pockets a card, same problem, so build a second identical stack from the other deck and keep it in your pocket.

**Hint if stuck.** "Cards. The one that's alone." Second hint: "Sort them."

## 5. Dominos: the 7

**Prep.** A full set of 28 dominos spread face down across the table or the floor, mixed up. On the back of the **3 | 4** tile, draw a small camera with a fine marker, the size of a thumbnail. Nothing on any other back. Emily is the photographer, so her mark is a camera.

**What they do.** Flip tiles looking for the camera, find 3 and 4, add them. Seven.

**Watch out.** Use a plain-backed set, not one with a pattern that hides the drawing. If your set has a logo on every back, draw the camera on a small round sticker instead and stick it on.

**Hint if stuck.** "Tiles. Find my camera." Second hint: "Add it up."

## 6. Balloons: the order

**Prep.** Thirty or more balloons, same colour, loose around the room. Before inflating one of them, roll up a slip of paper and push it inside. The slip says, in Emily's handwriting:

```
cups  cards  tower  tiles
```

Nothing else. This is the order of the four digits: the cup pong number goes first, the playing card number second, the Jenga number third, the domino number fourth. It uses the same four words as Emily's note, so once a kid has read the note the slip makes sense on its own. Inflate the rest with nothing in them.

**What they do.** Pop balloons until paper falls out. Loud, fast, fun, and it gives the kids who aren't good at the quiet puzzles a job.

**If you have helium.** Fill all of them with helium and tie them to the ceiling or let them float. The one with the paper in it sits lower, or doesn't float at all. Kids will notice the odd one out before they notice anything else. Without helium, they just pop everything, which also works.

**Watch out.** Give the leader in the room a pin, in case the last balloon standing is the one and nobody can pop it. Keep the balloons away from the cup pyramids.

**Hint if stuck.** "The order is in the air."

## Putting it together

Four numbers and a slip. Cups, cards, tower, tiles. 5, 8, 1, 7. One kid runs to the laptop at the main screen and types it. The screen validates on the fourth digit, so there's no Enter to miss.

If they type the four digits in the wrong order, the screen shakes red and clears. That's their cue to find the balloon if they skipped it.

## Running the room

- One leader in the room, not a suspect, with the note memorised. Melo or MM. Suspects stay out.
- Let it run on its own for five minutes. After that, give one hint for whichever game nobody has touched, using the exact line from Emily's note.
- After ten minutes, give second hints freely. Fifteen minutes is the cap. If they're still stuck at fifteen, the leader "finds" the balloon.
- Set up the room before service and keep the door closed. Cups last, since they're the easiest to knock over.
- Walk the room once as a kid would. Can you see the 1 from outside the tower. Is the camera visible on the domino from standing height. Is any balloon obviously heavier. Does the note come off the table in one pull. Are there exactly five balls in the room, all of them in cups.

## Shopping list

- 20 red cups, exactly 5 ping pong balls (keep any extras out of the room)
- Giant Jenga, one black marker
- Two poker decks (one for the stack, one for the spare stack)
- One domino set with plain backs, fine black marker, round stickers as a backup
- 30 or more balloons in one colour, a pin, helium if you want the floating trick
- Two index cards and a pen for Emily's note and the balloon slip, plus a spare of each
